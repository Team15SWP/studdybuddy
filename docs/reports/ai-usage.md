## AI Usage

Throughout the development process, AI tools (such as GitHub Copilot and ChatGPT) were used selectively to assist with **UI improvements** and **debugging**. Below is a breakdown of usage per week.

---

### Week 1

- Used AI to format project documentation in a clean and readable style.
- Minor bugfix suggestions in early login form and validation logic.

---

### Week 2

- AI-assisted layout improvements for the chat screen and task cards.
- Helped debug an issue with state management in Flutter (Riverpod).

---

### Week 3

- Applied AI recommendations to polish error message styles and button interactions.
- Identified and resolved a bug in backend registration logic with AI assistance.

---

### Week 4

- Used AI to clean up the README file and ensure consistency in wording and headings.
- Helped fix bugs in email validation and JWT session handling.

---

### Week 5

- AI used to suggest improvements in mobile responsiveness and padding in UI components.
- Helped locate a crash in the chat task submission flow.

---

### Week 6

- Mainly used AI to improve visual structure of forms and feedback screens.
- Debugged SQLite integration issues and assisted with fixing async Flutter bugs.

---

### Week 7

- Final touches to project presentation were styled with AI suggestions (font, spacing, layout).
- AI helped trace an edge-case bug in secure storage and login persistence.

---

> **Note:** AI was never used for full code generation. All core logic, architecture, and integrations were manually developed. AI was used only to enhance visual consistency and aid debugging when needed.
